# 智慧体育 - 运动识别

基于 TensorFlow.js 的实时骨架识别，支持多种运动计数。

## 功能特点

- ✅ 实时骨架识别
- ✅ 支持多种运动（高抬腿、深蹲、开合跳等）
- ✅ 无需后端，纯前端实现
- ✅ 适配微信小程序 WebView

## 使用方式

通过微信小程序打开，传递运动代码和名称：

```
index.html?code=high_knee_lift&name=高抬腿
```

## 技术栈

- TensorFlow.js (MoveNet)
- Canvas 2D
- MediaDevices API
